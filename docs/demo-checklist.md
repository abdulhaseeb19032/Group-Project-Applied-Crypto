# Demo Checklist

## Before Demo
- [ ] GitHub repository is open
- [ ] CSV server terminal is ready
- [ ] CSV client terminal is ready
- [ ] Sample CSV file is ready
- [ ] Apache secure site is ready
- [ ] Apache insecure site is ready
- [ ] Packet capture files are ready
- [ ] Screenshots are uploaded to GitHub

## CSV Demo Order
1. Show original CSV file
2. Run encrypt command
3. Show encrypted file
4. Run decrypt command
5. Show decrypted file
6. Run upload command
7. Show server received the file
8. Run server report command

## Web App Demo Order
1. Show secure HTTPS website
2. Show secure config
3. Show insecure HTTPS website
4. Show insecure config
5. Show openssl/curl result
6. Show packet capture

## Speaking Start
“Sir, I will first give a quick overview, then show the CSV Secure File Sync demo, then the HTTPS web app demo, and finally the packet capture analysis.”
