# 01 – Project Overview

## Project Title
Secure CSV File Sync and HTTPS Security Analysis System

## Overview
This project focuses on designing, building, testing and analysing secure client/server applications using cryptographic mechanisms.

Our group will build two applications:

1. CSV Secure File Sync
2. Secure Web App

The CSV Secure File Sync application will allow a client user to encrypt, decrypt and upload CSV files to a server. The Secure Web App will use Apache HTTPS with one secure configuration and one insecure configuration.

## Main Aim
The main aim is to understand how cryptography is used in real client/server systems. We will also capture packets and analyse the security protocols used during communication.
