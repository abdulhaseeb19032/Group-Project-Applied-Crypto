# COIT13240 Security Project Starter Plan

## Project title
Secure CSV File Sync and HTTPS Security Analysis System

## Project idea
This project demonstrates two secure client/server applications:

1. **CSV Secure File Sync**  
   A Python client and Python server that allow a user to encrypt, decrypt and upload CSV files securely.

2. **Secure Web App**  
   A real HTTPS web server with two configurations:
   - Secure configuration using recommended TLS settings
   - Insecure configuration using weak/old settings for comparison

## Main tools
- Python
- Python Cryptography Hazmat library
- HTTP
- Diffie-Hellman key exchange
- Apache web server
- HTTPS/TLS
- Wireshark or tcpdump
- GitHub
- Microsoft Teams

## Four member role plan

| Member | Main role | Main evidence |
|---|---|---|
| Member 1 | CSV client: encrypt, decrypt, upload | Client commands, screenshots, code commits |
| Member 2 | CSV server and key exchange | Server running, upload received, Diffie-Hellman explanation |
| Member 3 | Secure/insecure HTTPS web server | Apache config, browser/curl tests |
| Member 4 | Testing, packet capture and documentation | PCAP files, Wireshark screenshots, report structure |

## Important
This starter pack is not the final submission. Each member must understand, test and improve their own part.
If AI assistance is used, acknowledge it in the report.
