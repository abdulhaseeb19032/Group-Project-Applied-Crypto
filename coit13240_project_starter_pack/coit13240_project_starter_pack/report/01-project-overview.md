# 1. Project Overview

## Project title
Secure CSV File Sync and HTTPS Security Analysis System

## Aim
The aim of this project is to design, build, test and analyse secure client/server applications using cryptographic methods.

## Applications included
This project contains two applications:

1. **CSV Secure File Sync**
   - Python client
   - Python server
   - Local file encryption and decryption
   - File upload to server
   - Server-side receiving and decrypt/report function

2. **Secure Web App**
   - Apache web server
   - HTTPS secure configuration
   - HTTPS insecure configuration
   - Browser/curl testing

## Why this project is important
CSV files may contain private information. If the files are stored or uploaded without protection, an attacker may read or change them. This project uses cryptography to protect file data and also studies how HTTPS security depends on proper server configuration.
