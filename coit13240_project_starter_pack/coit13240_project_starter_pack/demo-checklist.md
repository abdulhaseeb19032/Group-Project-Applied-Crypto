# Demo Checklist

## Before demo
- [ ] GitHub repository opens
- [ ] All group members have commits
- [ ] Issues/tasks are visible
- [ ] CSV server can run
- [ ] CSV client can run
- [ ] Sample CSV file is ready
- [ ] Apache secure site works
- [ ] Apache insecure site works
- [ ] Packet capture files are ready
- [ ] Screenshots are ready

## Demo order
1. Open GitHub repository
2. Show project folder structure
3. Start CSV server
4. Run CSV encrypt command
5. Run CSV decrypt command
6. Run CSV upload command
7. Show server received file
8. Show secure HTTPS website
9. Show insecure HTTPS website
10. Open packet captures
11. Explain security protocol
12. Each member explains contribution
